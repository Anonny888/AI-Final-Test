# AI Final Quiz

เว็บข้อสอบ AI สำหรับนำขึ้น GitHub Pages

## วิธีใช้
1. เปิด `index.html` ในเบราว์เซอร์เพื่อทดสอบ
2. อัปโหลด `index.html` และโฟลเดอร์ `assets` ขึ้น GitHub repository
3. เปิด GitHub Pages จาก Settings → Pages → Deploy from branch → เลือก `main` และ `/root`
4. เว็บจะสามารถทำข้อสอบ ตรวจคะแนน ดูข้อที่ผิด และทำใหม่ได้ไม่จำกัด

### หมายเหตุ
- ระบบสุ่มลำดับข้อและตัวเลือกใหม่ทุกครั้งที่กดทำใหม่
- บทที่ 9 ข้อ 9 มีรูปโจทย์ `assets/cnn-q9.png`
- ข้อปลายเปิดที่ต้นฉบับไม่มีเฉลยจะไม่ถูกคิดคะแนน
